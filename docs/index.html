This page hosts a demonstration. Run the Python application locally to use the model. The video is an edited walkthrough of five actual browser screenshots, not a continuous recording.

MiniLM ranks eight curated activities; it does not generate instructions. Time and walking constraints are applied first. Some constrained requests produce a weak match. The examples are diagnostic checks, not an independent benchmark. No outdoor field trial or behavioral benefit has been measured. AI assisted code, mission writing and documentation.
